# 项目规划与计算内核说明

## 多根钢束批量计算规划（2026-09-19）

在保持现有单根手动计算功能的前提下，新增“多根批量计算”工作模式。首期数据来源为固定模板的 Excel 导入；CAD 批量导入仅保留后续入口。

### Excel 输入约定

工作簿包含四张固定工作表：`钢束清单`、`立面线形`、`平面线形`、`默认参数`。

- `钢束清单`：编号、立面编号、平面编号、左端应力、右端应力、k、μ、Ep；单束参数为空时继承默认参数。
- `立面线形`、`平面线形`：线形编号、x、y、b。线形可被多根钢束共享。
- 编号填写“直线”时，从另一方向线形的首尾 x 自动生成两节点的零 y、零 bulge 直线；两方向不得同时为“直线”。
- 平、立面线形均统一为 x 严格递增，并校核首尾 x 在 0.001 m 容差内一致。
- 工作簿在默认参数中指定统一单位 m 或 mm。

### 前端批量工作流

多根模式包含 Excel 与后续 CAD 两个来源入口。Excel 导入后先展示导入校核摘要和钢束总览；可批量计算，再通过总览行或可搜索选择器查看某根钢束的平、立面、解析后的参数、结果卡片、四联图和分段明细。首期导入数据为只读预览，避免网页编辑与源 Excel 脱节。

### 成果导出

计算结果导出为新的 `.xlsx` 文件，保留四张输入表，并在`钢束清单`后追加计算状态、错误信息、总长、累计转角、不动点、左右端及总伸长量。另提供`分段明细`与`导入与计算说明`工作表。批量中单根失败不阻断其余钢束计算或导出。

## 1. 项目目标

将现有的预应力钢束理论伸长量计算脚本，逐步完善为可复核、可追溯的工程计算工具。工具的首要目标是正确计算理论伸长量，并清晰展示钢束几何、摩阻应力分布和分段计算过程；后续再扩展工程管理、实测值校核与报表导出能力。

## 2. 技术路线

正式工具暂定采用前后端分离架构：

```text
前端：React + TypeScript
后端：Python + FastAPI
数据：初期 SQLite，后续可迁移 PostgreSQL
报表：Excel 导入导出与 PDF 计算书
```

预应力计算公式必须作为独立的 Python 计算内核，不依赖网页、数据库或 Excel。这样未来无论采用网页、桌面 EXE 或批量脚本，都可以复用同一套经过验证的计算逻辑。

Python 运行环境以 Python 3.14 为目标。项目根目录已创建 `.venv` 虚拟环境，并通过 `pyproject.toml` 固定 Python 版本和依赖；`.venv` 不提交到 Git。参考脚本对比所需依赖可在项目根目录执行以下命令安装：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[reference-comparison]"
```

## 4. 原有脚本的计算思路

参考脚本 `ref/tendon_new6_CanCutArc.py` 的主流程为：

1. 由立面与平面线形重建钢束空间线形；
2. 根据 `x1`、`x2` 对钢束进行截取；
3. 计算钢束空间长度与累计角变位；
4. 按孔道摩阻关系计算两端应力衰减；
5. 单端张拉时按张拉端应力积分；双端张拉时确定两端应力曲线交点，分别累计两侧伸长量；
6. Excel 批处理脚本读取钢束、立面、平面数据后，将结果回写工作表。

原脚本中直线插值的分母错误已经在 `ref/tendon_new6_CanCutArc.py` 中修正为 `self.p2[0] - self.p1[0]`。该问题主要影响截取端点落在斜直线段内部的工况。

## 5. 新计算内核框架

当前已实现第一版内核：

- `backend/app/calculations/geometry.py`
  - `Line`：共同里程 `x` 参数化的二维直线；
  - `Arc`：以 CAD bulge 描述的二维圆弧；
  - `Profile`：由直线、圆弧组成的平面或立面线形；
  - `TendonGeometry`：将平面与立面合成为空间钢束，提供空间长度与累计角变位计算。

- `backend/app/calculations/elongation.py`
  - `FrictionParameters`：孔道偏差系数 `k`、摩阻系数 `μ`；
  - `MaterialParameters`：钢束弹性模量 `Ep`；
  - `TensioningCase`：单端或双端同步张拉端应力；
  - `TendonElongationCalculator`：计算摩阻应力衰减和理论伸长量；
  - `CalculationResult`、`SegmentResult`：输出总长度、累计转角、左右端伸长量、总伸长量、平衡点及分段计算明细。

计算内核采用无状态设计：相同的输入必须产生相同的输出，计算过程不会向钢束对象追加缓存数据。这样可以避免旧脚本多次调用后控制点、分段应力被重复累加的问题。

当前几何模型要求立面和平面共用同一里程 `x`，且 `x` 方向单调增加。空间累计角变位通过相邻空间单位切向量夹角离散累计，单位为弧度。

## 6. 已有测试

`backend/tests/test_elongation.py` 包含两个基础算例：

1. 无摩阻单端直线束，验证 `ΔL = σL / Ep`；
2. 无摩阻、两端等应力的直线束，验证左右两端各承担半束理论伸长量。

`backend/tests/test_reference_comparison.py` 包含一个新旧程序回归对比算例：采用参考脚本中的立面、平面组合曲线工况，对比总长度、左右端及总理论伸长量。当前对比结果如下：

```text

总伸长量（m）        0.496372886        0.496372646         0.000000241
左端伸长量（m）      0.248219301        0.248219173         0.000000128
右端伸长量（m）      0.248153585        0.248153472         0.000000113
```

该参考脚本算例在 SciPy 数值积分时会产生“达到最大分段数”的警告，但输出结果与新内核高度一致。后续应继续加入实际工程钢束和截取工况，作为回归测试数据。

新内核会在一次计算开始时预生成“里程—累计长度—累计转角”路径表，后续应力查询和伸长量积分均从该表插值，不再嵌套调用几何积分。以本组合曲线算例计时，参考脚本约为 1.0 秒，新内核约为 0.23 秒，约快 4.4 倍。

## 7. 当前适用范围与限制

当前内核仅用于即时理论伸长量计算，已经支持单端张拉、双端同步张拉、直线和圆弧线形。

- 分步、非同步双端张拉；

- 从 Excel/CAD 导入线形；
- 实测伸长量录入、允许偏差判断和计算书导出。

## 9. 网页 MVP 结论

网页 MVP 定位为“单根钢束快速复核器”，暂不实现账号、工程库、Excel/CAD 文件导入和计算书导出。前端采用 React + TypeScript + Ant Design，后端采用 FastAPI 调用现有 Python 计算内核。

MVP 页面包含以下四个区域：

1. 立面线形与平面线形输入；
2. 摩阻、材料和张拉参数输入；
3. 总长度、累计转角、不动点、左右端及总理论伸长量；
4. 分段长度、转角、平均应力和伸长量明细。

立面和平面均应支持两种输入方式，并在界面中分别切换：

| 输入方式 | 数据格式 | 使用场景 | 字段含义 |
| --- | --- | --- | --- |
| 角点 + 倒角半径 | `x / y / r` | 设计阶段手工建模 | 每个中间控制点的 `r` 为倒角圆弧半径；首末点 `r` 被忽略，`r=0` 表示保留直线折点。 |
| CAD 节点 + bulge | `x / y / b` | 复核已有 CAD 钢束 | 每行 `b` 属于“当前点到下一点”的分段；`b=0` 表示直线，`b≠0` 表示圆弧；最后一行 `b` 被忽略。 |

两种输入均在后端转换为统一的 `Line / Arc → Profile → TendonGeometry` 几何对象，后续摩阻和伸长量计算不区分输入来源。内核已提供 `Profile.from_xyr_points(...)` 与 `Profile.from_xyb_points(...)` 两个解析入口，并有测试验证二者可生成一致的圆弧线形。

MVP 默认值暂定为：`k=0.0015`、`μ=0.25`、`Ep=195000 MPa`、双端张拉且两端应力均为 `1395 MPa`；所有默认值可修改，并应提示用户以设计文件或试验资料为准。内部长度单位使用 `m`，界面结果同时显示 `m` 和 `mm`。

页面应提供立面、平面及简化空间钢束预览；提交计算前校验里程递增、相邻线形连续、倒角半径有效、圆弧在共同里程方向单调，以及立面和平面起终里程一致。建议提供“加载示例”按钮，直接填充已验证的组合曲线算例。

### 9.1 计算结果四联图

计算完成后，页面应以共同里程 `x（m）` 为横轴，输出四个上下对齐、共享横轴的图形；不要在同一坐标区堆叠四个纵轴。四个纵轴依次为：

1. 平面偏移 `y（m）`；
2. 立面高程 `z（m）`；
3. 钢束最终采用应力包络 `σ（MPa）`；
4. 相对不动点的累计理论伸长量 `ΔL（mm）`。

第 4 图的伸长量不是应变或单位长度伸长率。双端张拉时，应以不动点为零值：从不动点向左累计，到左端的值为左端理论伸长量；从不动点向右累计，到右端的值为右端理论伸长量。因此曲线在不动点处为 `0 mm`，并向两侧逐渐增大，左右端终值可以不同。

图形展示规则如下：

- 展示线形控制点与分段关键点，但不堆叠额外文字；
- 用醒目的贯穿竖线和简短标签标明不动点；
- 应力图仅展示最终采用的应力包络，并在不动点处用小圆点标记；
- 鼠标悬停任意里程时，显示该处平面坐标、立面坐标、应力和相对不动点的累计伸长量；
- MVP 暂不展示左右端独立应力传递曲线。

### 9.2 本轮 MVP 实现更新

当前 MVP 已完成首轮可用界面，前端为 React + TypeScript + 原生 CSS，后端为 FastAPI；不依赖 Ant Design。已实现内容如下：

- 立面、平面线形均可切换 `x/y/r` 与 `x/y/b` 输入方式，表格支持单元格编辑、拖动或 Shift 框选，以及从当前焦点单元格开始粘贴 Excel 的多行多列数据；仅在粘贴数据超过现有行数时增加行。
- 页面提供居中的立面、平面线形简图；删除节点使用弱化的灰色细叉号，输入方式下拉框与参数区采用紧凑布局。
- 参数区与结果区以横向分割线区分。主要结果卡片依次为：钢束总长、累计转角、不动点、左端伸长量、右端伸长量、总伸长量。
- 四联图使用共同横轴并提供 5 段刻度、水平与垂直网格线、各图边框、分行的纵轴名称和单位，以及随鼠标定位的数值提示。平面、立面图分别标记各自线形中直线—圆弧的切点；伸长量图名称简化为“伸长量”，纵轴下限固定为 `0 mm`。
- 分段明细按固定表格布局展示：序号、伸长方向、起终里程、长度、转角、平均应力、本段伸长量及累计伸长量，并在不动点相邻两段之间以红色虚线分隔，不另设不动点数据行。
- 张拉端应力输入 `0` 表示该端不参与张拉。例如左端 `0 MPa`、右端 `1395 MPa` 按右端单端张拉计算；两端均为 `0 MPa` 会返回“至少需要提供一个张拉端应力”的校验错误。

本轮已执行前端生产构建验证；截至当前，`backend/tests` 自动化测试共 17 项通过。`ref/` 继续仅作为参考脚本目录，不纳入 Git 版本管理。

## 10. 当前实现进度（2026-09-20）

单根钢束计算与多根钢束批量计算均已具备可用版本。前端提供“单根手动计算”和“多根批量计算”两种工作模式，批量模式支持固定 Excel 模板和 DXF 两种数据来源。

### 10.1 单根计算现状

- 支持 `x/y/r` 与 `x/y/b` 两种线形输入；单元格可从 Excel 粘贴，新建节点和一键清空均默认填入零值。
- 输入数值按 3 位小数显示，但保留原始数值参与计算。
- 四联图包含平面、立面、应力和伸长量；纵轴上限严格取对应数据的最大值，不额外留白。提示框会随鼠标移动，并在右侧自动翻转至鼠标左边。
- 平、立面关键点各自独立绘制；不动点、分段结果、左右端及总伸长量均可复核。

### 10.2 批量 Excel 导入

- 固定工作表仍为 `钢束清单`、`立面线形`、`平面线形`、`默认参数`。
- 钢束清单支持共享线形和“直线”引用；导入后可全部计算、逐束查看、导出成果 Excel。
- 钢束总览展示总长、左右端伸长量和总伸长量；分段明细与单根模式保持一致，并在不动点两侧用红色虚线分隔。
- 若平、立面首尾 x 差不超过 `0.001 m`，导入后会将对应端点取中值统一为共同里程，再交给要求端点严格相等的计算内核；超过该阈值仍拒绝导入。

### 10.3 批量 DXF 导入

DXF 批量导入的图层与实体约定如下：

- `平面` 图层：可包含多条开放二维多段线；
- `立面` 图层：可包含多条开放二维多段线；
- `钢束编号` 图层：仅允许单行文字 `TEXT`，不支持 `MTEXT`；
- 每条多段线会自动标准化为 x 从小到大；编号文字的实际对齐点应位于该线形最左端点附近；
- 同一编号的平、立面线形自动配对为一根钢束。文字为左、右或居中对齐时，均读取其实际对齐点，而非单纯读取插入点；
- 图纸单位仅作用于 DXF 导入，可选 `m` 或 `mm`，导入后统一换算为 m；编号匹配容差固定为 `0.05 m`，不对用户开放修改。

导入会明确拒绝缺少线形、编号文字未匹配、一个编号对应多条线形、`MTEXT`、闭合或非二维多段线，以及平立面首尾 x 差超过 `0.001 m` 的情形。`demo/` 目录用于保存单根 DXF、多根 DXF 和批量 Excel 的可导入示例；其中多根 DXF 的编号文字使用右对齐，已用于验证实际对齐点匹配逻辑。

### 10.4 界面与验证状态

- 批量数据来源区中，Excel 导入与 DXF 单位/导入按钮以淡显竖线区分，避免误认为图纸单位会影响 Excel。
- 钢束总览与分段明细采用“序号窄列、其余列等宽”规则；只读线形表的 x、y、b 三列等宽，并保留左右边距。
- 当前后端自动化测试共 17 项通过；前端生产构建通过。

后续建议优先处理：批量导入后按项目需要编辑或批量覆盖张拉参数；增加 DXF 导入校核结果的逐根清单；再考虑实测伸长量、偏差判定和计算书导出。
